隱私權政策

擴充功能名稱：[B.M] 自動簽到（以下稱「本擴充功能」）。

本政策說明本擴充功能如何處理與您相關的資訊。使用本擴充功能即表示您同意本政策內容。

一、資料收集

本擴充功能不會向開發者蒐集、上傳或出售任何可識別個人身分的資料（例如帳號、密碼、電子郵件、Cookie 內容或瀏覽紀錄）。本擴充功能沒有開發者自有的後端伺服器。

本擴充功能未使用分析（Analytics）、廣告追蹤或遠端程式碼；所有程式皆隨擴充功能套件封裝。

本擴充功能不會儲存或讀取您的網站密碼。簽到係在您裝置上、使用您瀏覽器中既有的登入工作階段完成；請您事先在 Chrome 手動登入各支援網站。

二、本機儲存

本擴充功能使用瀏覽器的 storage 權限，僅在您的裝置上保存下列資訊，供擴充功能本身讀取：

  • 每日簽到時間與各網站的啟用開關。
  • 各網站最近一次簽到結果（成功、尚未登入、需要驗證碼、逾時或失敗）及時間。
  • 簽到進行中的暫存狀態（例如目前開啟的分頁）。

上述設定不會傳送至開發者伺服器。

三、運作方式與權限範圍

本擴充功能的單一目的是：依您指定的時間（或手動「立即簽到」），在您已登入的支援網站上完成每日簽到，成功後關閉分頁。

目前支援的網站為：

  • 巴哈姆特（gamer.com.tw）小屋簽到頁
  • APK.TW（apk.tw）
  • 原神 HoYoLAB 簽到活動頁（act.hoyolab.com）

為達成上述功能，本擴充功能會：

  • 使用 alarms 在您設定的本地時間排程簽到，並處理逾時與工具列徽章清除。
  • 使用 tabs 開啟、聚焦或關閉簽到分頁；若偵測到導向登入頁，會保留分頁並提示您手動登入。
  • 使用 scripting 與內容腳本，在上述網站分頁內呼叫該站既有的簽到介面或官方活動 API（僅在您裝置上的該分頁內執行）。
  • 使用 notifications 在本機顯示簽到結果（例如成功、需要驗證碼或尚未登入）。
  • 使用 host_permissions 僅存取上列支援網站及其簽到相關網域，以便載入頁面並完成簽到。

若簽到需要驗證碼、尚未登入或發生錯誤，分頁會保留供您手動處理；本擴充功能不會因此將頁面內容回傳給開發者。

四、第三方服務

您使用巴哈姆特、APK.TW、HoYoLAB／HoYoverse 等網站時，該等網站可能依其自有隱私權政策與服務條款處理資料（包含其既有 Cookie 與登入工作階段）。該部分與本擴充功能無涉，請參閱各網站之說明。

本擴充功能為第三方輔助工具，與上述網站官方無關。

五、政策變更

若本擴充功能之資料處理方式有重大變更，將於本頁面更新；建議您不定期查閱本政策。

六、聯絡方式

若您對本政策有疑問，請透過 Chrome 線上應用程式商店 上本擴充功能頁面所提供之開發者聯絡方式，或 GitHub 專案 Issues 與維護者聯繫。
